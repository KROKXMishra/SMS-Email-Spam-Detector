# SMS & Email Spam Detector

A Machine Learning web application that classifies SMS and Email messages as Spam or Ham using NLP and Naive Bayes.

## Features
- Spam/Ham Detection
- Confidence Score
- NLP Text Preprocessing
- Glassmorphism UI
- Deployed on Render

## Tech Stack
- Python
- Flask
- Scikit-Learn
- NLTK
- HTML/CSS
